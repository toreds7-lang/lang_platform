    ⌨ Shortcuts
    Modified mode shortcuts: A = previous sentence   S = repeat sentence   D = next sentence
    Speak aloud: R = read the sentence with TTS
    Speak a selection: select any text, then T = speak it in the language you are learning   Shift+T = speak it in English. Works inside the explanation popup and the chat too.
    Esc = pin this sentence & pause the video, so TTS keeps speaking it instead of following playback. Esc again to resume.
    Explanations: double-click a word   E = sentence in easy English   G = grammar
    Breakdown: O (or Alt+O) = translate the sentence, then gloss it part by part, with a dictionary-form vocabulary list you can copy straight into Anki. Select a phrase first to break down just that phrase.
    R, E, G and O all target the sentence your mouse is on (or the highlighted one). Alt+S also works for E.
